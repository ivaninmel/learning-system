# 学习记录与专注监督

一个面向小学生的本地桌面应用：把日程打卡、结构化复盘、B 站学习行为记录和置顶专注小窗放在一个简洁界面中。所有数据保存在本机 SQLite 数据库，不需要账户或服务器。

## 安装与运行

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

> 首次安装 PySide6 会包含网页视图组件；若环境缺少该组件，B 站搜索会自动改由系统浏览器打开，数据记录功能仍可使用。

## 使用方式

- **日程与打卡**：新增快捷标签后可一键记录当前时间；日期和时间都可鼠标点选或键盘输入。单击已记录日程即可编辑，双击关联项可打开复盘。
- **复盘卡片**：内置生活复盘、信奥复盘，并支持新增板块和临时增加记录项目。单击右侧卡片可载入、补充和更新内容。
- **B站学习**：点击“打开纯净学习窗口”会启动应用受控的 Electron Chromium 窗口（不会调用默认浏览器），从而播放 B站 H.264 视频。搜索、进入视频的标题、链接和关闭窗口时的学习时长会自动写回本应用。
- **悬浮小窗**：默认出现在右上角。打开时会最小化任务栏中的其他普通窗口；开始后仅显示目标、提醒和倒计时，支持停止并累计专注时间，停止后立即关闭切换窗口确认。

## 本地数据模型

- `quick_tags`：常用活动预设。
- `schedules`：日程及其可选的复盘关联 ID。
- `review_categories`、`reviews`：可扩展的复盘分类和卡片内容（JSON 字段）。
- `video_logs`：搜索、开始播放、学习结束等 B 站行为记录。

数据库路径：`data/learning_system.db`。

## B站播放组件

首次配置已在项目中下载 Electron Chromium 运行时。启动主应用后，在 **B站学习** 页面输入搜索词或视频链接即可打开专属学习窗口；不要直接运行 `electron_bili/main.js`，这样日志才会自动回写主应用。搜索结果中打开任意视频都会被强制留在同一受控窗口，并自动记录标题、链接和停留时长，不向孩子询问是否“学习相关”。
